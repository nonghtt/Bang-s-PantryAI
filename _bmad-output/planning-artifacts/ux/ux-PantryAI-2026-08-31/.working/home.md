# 홈 + 이동 구조 — 캡처 2026-09-01

이동: 하단 탭 바 4개 **홈 · 추천 · 재료 · 회고**. 어디서든 1터치. 설정(⚙)은 홈 상단 아이콘 → 기호·알레르기(FR-5)·라이선스 고지(NFR-11).
진입: 온보딩(상비 칩 → 재료 화면 → 다음) 끝에 도착. 이후 앱을 열면 홈.

| 순서 | 블록 | 조건 | 동작 |
| --- | --- | --- | --- |
| 1 | 조리 확인 질문 카드 | 승인 1건이 있고 아직 답하지 않음 | "해먹었어요" → 소진 판정 / "안 해먹음" → 승인 취소(FR-11). 문구·시점은 U9 |
| 2 | 승인한 레시피 카드 "오늘 만들 것" | 승인 1건 있음 | 누르면 레시피 상세(U7). 지하철에서 승인 → 집에서 다시 여는 자리 |
| 3 | 추천 진입 버튼 | 항상 | → 추천 탭 화면 |
| 4 | 최근 해먹은 요리 1~2건 | 이력 ≥ 1 | 누르면 회고 탭. 0건이면 블록 없음 |

없음: 재고 요약(버림 — 재료 탭이 있음).
빈 홈(첫 도착): 블록 3만. 조리 확인·승인·이력이 모두 없다.
버린 구조: B 허브 홈 + 하위 화면(항상 홈 경유, 2터치) / C 홈 = 추천 요청 화면(기능 화면과 조건부 카드가 경합).
계측: 세션 시작(홈 진입) · 조리 확인 OK / 승인 취소(사유=안 해먹음)는 카드 버튼에서.
