# 재료 화면 — 온보딩 2/2 "냉장고 재료 추가" = 이후 "재고 관리 페이지" (같은 화면, 진입 맥락만 다름) — 캡처 2026-09-01

| 요소 | 상태 |
| --- | --- |
| 검색바 | 최상단 고정. 표준명 + 이표기(FR-2). 결과 항목은 표준명으로 렌더링(닭가슴살 입력 → '닭고기'), 재고도 표준명. 입력창 텍스트만 친 그대로 |
| 어휘 밖(U3) | 결과 0건 자리에 '<입력> 그대로 추가'. 표준명 없음. 분류 행 맨 끝 '직접 추가' 칸에 모임 [ASSUMPTION] + '레시피 매칭 안 됨' 상시 구분 |
| 분류 행 | 검색바 아래 가로(x축) 스크롤. 10개 안팎(고기류·과채류 …, `u2-taxonomy-top10.md` 초안). 터치 = 그 분류만 목록에. 기본 = 첫 분류 [ASSUMPTION] |
| 목록 | 선택 분류의 **전체 재료**가 칩으로. **가진 것만 표시**(표현 미정 → DESIGN.md). 고정 순서(라벨 파일 순) |
| 칩 | 터치 = 재고에 넣기/빼기 토글. 확인 없음, 즉시 반영. 되돌리기 = 재터치 |
| 면제 재료 | 7종(자동 보유)은 따로 접힌 구획, 목록 아래 [ASSUMPTION]. 펼치면 칩, 끌 수 있음 |
| 빈 상태 | 전부 끄면 빈 냉장고. 특별 화면 없음 |
| 온보딩 진입 | 하단 바 "N개 선택"(누르면 이번 단계에서 고른 목록) + 다음 → 홈. 0개 추가로도 진행 [ASSUMPTION: 하단 바는 온보딩에서만] |
| 재고 관리 진입 | 홈에서. 하단 바 없음. 소진 판정 직후 갱신된 상태로 보임(FR-4) |
| 계측 | 재고 변경(추가/제거, 출처 = 검색 / 자유 입력) · 어휘 밖 항목 수 · 온보딩 진입 시 SM-C1 타이머 종료(홈 도착) |

버린 형태: B 2단 왼쪽 세로 탭(처음 골랐다가 정정) / A 세로 그룹 목록+분류 칩(점프형) / C 아코디언 / D 분류→하위 화면.
