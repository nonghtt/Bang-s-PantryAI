# PRD Addendum — 본문에 담지 않지만 버리면 안 되는 것

> PRD는 "무엇을"만 말한다. 여기에는 "어떻게"에 가까운 것, 버린 선택지의 근거, 다음 문서(아키텍처·UX)로 넘기는 것을 둔다.

## 1. 아키텍처로 인계하는 선호

### 아키텍처가 받아야 할 확정 사항 (PRD 본문에서 파생)

| 확정 | 출처 | 아키텍처에 미치는 것 |
| --- | --- | --- |
| 런타임에 공공 API를 호출하지 않는다 — 빌드 시점 1회 배치 적재 | FR-15, 브리프 Addendum §1 | 배포 서버 IP 등록 불필요 → 서버리스 열려 있음 |
| 정규화·분류는 빌드 시점 배치, 실행 시점 LLM 호출 0 (표준명 문자열 비교만) | FR-16, D-029 | 실행 경로에서 LLM 비용은 자연어 조건 질의(FR-27)에만 발생 |
| 재고는 유무만 — 수량 필드 없음 | FR-3, D-013 | 재고 스키마는 `(user, 표준명, 등록시각)` 수준. 등록시각은 2차 FR-24용으로 1차부터 저장 |
| 재고 입력은 표준명 어휘 검색이 기본이되 어휘 밖 자유 입력도 재고에 들어간다(매칭 안 됨) | FR-2, A7 | 실행 시점 정규화 경로는 1차에 없음; 이표기 → 표준명 검색 인덱스 + 어휘 밖 항목 저장·로깅 필요 |
| 조리 확인은 첫 화면 + 푸시 | FR-11 | 웹 푸시(PWA) vs 네이티브 — 폼팩터 결정(§8-1)에 종속 |
| 계측 이벤트 5종을 1차부터 로깅 | NFR-13 | 이벤트 스키마·집계 경로가 1차 범위 |

### 백엔드 스택 갈림길 — 브리프 Addendum §6 참조

Spring Boot(강점 연속) / Python·FastAPI(LLM 생태계) / 하이브리드. 결정은 아키텍처에서. 판단 기준은 "무엇을 증명할지" — 브리프 Addendum §5의 강점·공백 지도(RAG 직접 구축·React·공개 실서비스·인프라가 공백, 성능·정합성·관측이 강점).

**새 입력 — LangChain 선호 (2026-08-30, 사용자 입력).** LLM이 하는 일(정규화·분류·자연어 조건 질의·2차 자연어 기록·3차 식단 구성)을 프롬프트 문자열이 아니라 **코드 구조로 관리**하고 싶다 — 도구·체인·에이전트 루프가 코드에 드러나야 한다. 사용자 스스로 "청사진보다 구현에 가깝다"고 인지했다. LangChain은 Python 생태계가 본진이므로 이 선호는 FastAPI 또는 하이브리드 쪽에 무게를 싣는다. 미검증: LangChain을 쓴 결과가 측정 축(§7)에 어떻게 연결되는지는 아키텍처에서 답해야 한다 — "붙였다"에서 멈추지 않으려면.

## 2. 버린 선택지와 근거 (PRD 본문에 남기지 않은 것)

브리프를 뒤집은 결정(수량 추적·차감·원본 표기 병기·커버리지 목표)은 PRD §6.3이 정본이다. 여기에는 그 외 버린 선택지만 둔다.

| 버린 것 | 대신 택한 것 | 왜 | 기록 |
| --- | --- | --- | --- |
| 통계 탭을 1차로 확장 | 브리프대로 최소 회고 | 사용자 결정(정정). 이연 항목 1순위 | memlog #53→#54 |
| 요리 계통 5종 대신 요리 형태 축(`RCP_PAT2`)을 다양성 지표로 / 이중 축 | 5종 유지, 형태 축은 지표로 쓰지 않음 | 요리 계통은 측정 축이 아니라 제품 기능 축. 측정 편의로 제품을 바꾸지 않는다 | D-043 |
| 원천 라벨을 따라 `카레` = 동남아 | 카레는 재료, 계통 신호 아님 | 카레 22건 대부분이 한식·양식. 비어 있는 칸을 채우려고 판정을 느슨하게 하는 것이 된다 | D-044 |
| 만개의레시피(10만+) · RecipeNLG · 크롤링 | 공공데이터 4종 | CC BY-NC-ND의 ND가 LLM 파싱·정규화·임베딩과 정면 충돌 | D-003, 브리프 Addendum §4 |
| "재료당 평균 요리 가짓수 2.5" 지표 | 서로 다른 요리 수 + 재료별 사용 횟수 | 체감 불가·코퍼스 상한 1.50으로 도달 불가·다양성이 아니라 빈도를 잼 | D-008 |
| 접두어 제거 규칙 기반 정규화 (가드 없음) | LLM + 가드 있는 규칙 사전 선행 | `간장→장`, `생크림→크림`으로 깨짐; 가드를 두면 규칙 사전은 정밀도 100% | D-012→D-030 |

## 3. 측정 자료의 위치

PRD §7의 수치는 전부 아래에서 재현된다. PRD는 수치를 인용만 한다.

- 결정 이력 전체: `docs/career-source.md` (D-001~D-047, 인덱스 자동 생성)
- 정규화: `data/labels/stage2_full_output.csv.score.md` · `stage2_full_review.md` · 정답 `ingredient_standard_answers.csv`(528행) · `context_dependent_rows.csv`(23행)
- 분류: `data/labels/category_full_output.csv.score.md` · `category_full_review.md` · 정답 `category_answers.csv`(120행) · 규칙 `category_README.md` · 스냅샷 `spec-snapshot/`
- 커버리지: `scripts/measure_coverage.py` · 재고 가정 `pantry_assumption.txt`
- 1단계 정제 보고서: `data/processed/report.md` (스크립트 생성)
