# 재료명 표준 사전 — 정답 세트와 사전 초안

이 폴더는 **재료명 정규화의 인수 기준**이다. LLM 정규화 결과를 여기에 대조해 일치율을 낸다.

```
ingredient_standard_answers.csv    정답 세트 528행 — 사람이 판정. LLM 채점 기준
ingredient_dictionary_draft.csv    사전 초안 1,438종 — 규칙이 생성. 검수 대상
archive/ingredient_standard_raw.csv  1차 미기입본 500행 — 개선 전후 대조용. 수정하지 않는다
```

> **작성 순서 규칙**: 정답 세트는 **LLM 정규화를 돌리기 전에** 채운다. 돌린 뒤에 채우면
> 사람이 LLM이 낸 답을 보고 정답을 쓰게 되어 정확도 수치가 의미를 잃는다. (D-020)

---

## 1. `ingredient_standard_answers.csv` — 정답 세트

병합 코퍼스 1,966종 중 **빈도 4 이상 528종**. 전체 재료 행 18,988건의 **89.7%**(17,041건)를 덮는다.
꼬리의 희귀 재료는 사용자 재고에 들어올 가능성이 낮아 정규화 오류가 추천을 거의 바꾸지 않는다. (D-020)

| 컬럼 | 채우는 주체 | 내용 |
| --- | --- | --- |
| `묶음` | 자동 | 1차 가공의 배치 흔적. **판정이 아니다** — 같은 묶음이어도 다른 재료일 수 있다. 315 이상은 2차 추가분 |
| `재료명` | 자동 | 원본 표기 |
| `빈도` | 자동 | 코퍼스 등장 행 수 |
| `출처` | 자동 | `농`=농정원 · `식`=식약처 · `농식`=양쪽 |
| **`표준명`** | 사람 | 이 재료를 무엇으로 접을 것인가 |
| **`판정`** | 사람 | 아래 4값 중 하나 |
| `메모` | 사람 | 판단의 근거·반례·미검증 표시 |

### 판정 4값 (D-023)

| 값 | 조건 | 예 |
| --- | --- | --- |
| `그대로` | **표준명 == 재료명** | `양파` → `양파` |
| `표기` | 같은 물건, 철자·띄어쓰기·이명 차이 | `달걀` → `계란` |
| `가공` | 원물에 형태 변화 (다진·즙·건조·가루) | `다진마늘` → `마늘` |
| `제외` | 재고 대상이 아님 | `청정원맛선생`(브랜드 상품명) |

`그대로`는 표준명이 자기 이름일 때만 쓴다. 이 규칙 하나로 판정 대부분이 기계적으로 결정된다.
**역방향도 성립해야 한다** — 표준명이 다른데 `그대로`이거나, 표준명이 같은데 `표기`/`가공`이면 오류다.

> 이전 지침의 `별개`·`부위`는 폐기했다. `별개`는 표준명이 자기 이름이면 `그대로`와 구별되지 않는 중복이었고,
> `부위`는 `가공`에 포함된다.

## 2. 접는 기준

> **품종은 구분한다. 가공 상태와 부위는 통합한다.** (D-010)

판정이 갈리면 이 질문으로 자른다.

> **재고에 A가 있을 때, B를 요구하는 레시피를 실제로 만들 수 있는가?**

| | 판정 |
| --- | --- |
| 통마늘 → 다진마늘 필요 | 다지면 된다 → **통합** |
| 소고기 → 등심 필요 | 부위는 대체 가능 → **통합** |
| 대파 → 실파 필요 | 굵기가 다른 재료 → **구분** |
| 표고 → 팽이 필요 | 식감·용도가 다르다 → **구분** |
| 생표고 → 말린표고 필요 | **건조는 되돌릴 수 없다 → 구분** |

### 판별이 애매할 때 — 동시 등장을 센다 (D-028)

**같은 레시피에 함께 나오면 다른 물건이다.** 한 요리에 두 이름을 다 적었다는 것은 작성자가 구분했다는 뜻이다.

```
청주 & 맛술    4건 함께 등장  → 다른 물건. 합치면 안 된다
청주 & 정종    0건            → 같은 물건. 병합
```

> ⚠️ **0건은 필요조건이지 충분조건이 아니다.** 배추김치·백김치·열무김치는 전부 0건이지만 다른 재료다 —
> 한 요리에 두 종류의 김치를 넣을 일이 없어 0이 나올 뿐이다. **용례가 겹치는지를 함께 봐야 한다.**
> 쌀과 밥은 같은 요리군(볶음밥·죽·비빔밥)에 나타났지만, 배추김치(찌개·전)와 백김치(샐러드·말이)는 요리군이 완전히 분리됐다.

### 확정된 개별 기준

| 축 | 기준 | 근거 |
| --- | --- | --- |
| 조리 단계 차이 | **통합** — `밥`·`찬밥`·`현미밥` → `쌀` | D-021 |
| 결과물이 달라지는 차이 | **구분** — 화이트와인 ≠ 레드와인, 올리브유 ≠ 식용유 | D-022·D-024 |
| 가루 | **집에서 원물로부터 만드는가** — 잣가루→잣(통합) / 생강가루(분리) | D-027 |
| 즙 vs 주스 | **짜낸 즙은 원물, 주스는 가공식품** — 용량으로 갈린다(즙 1~10g, 주스 50~200g) | D-033 |
| 판별 근거가 없을 때 | **구분을 만들지 않는다** — "후추 약간"이 통후추인지 가루인지 모르면 합친다 | D-027 |

### 확정된 표준 표기

`계란`(달걀 아님) · `소고기`(쇠고기 아님) · `올리브유`(올리브오일 아님) · `주꾸미` · `콜리플라워` · `래디쉬` · `샐러리`

**빈도가 기본값이고, 거스를 때는 메모에 사유를 남긴다.** 위 표기 중 `계란`·`소고기`·`고추냉이`는
빈도 우세한 쪽을 의도적으로 버린 것이라 각 행 메모에 이유가 적혀 있다.

## 3. `ingredient_dictionary_draft.csv` — 사전 초안

정답 세트 밖 1,438종에 규칙을 적용한 결과다. **정답 세트가 아니다** — 채점 기준으로 쓰지 않는다.

| 신뢰도 | 규모 | 처리 |
| --- | --- | --- |
| `A` | 150종 218건 | 공백·`다진`·`불린`·`깐`·`살` 등 **형태만 바꾸는 수식어**. 동시 등장 검사로 전량 확인, 오류 0 → **자동 확정 가능** |
| `B` | 25종 36건 | `생`·`적`·`흰`·`냉동` 등 **품종을 가를 수 있는 수식어**. 검수에서 4종 오류 발견 → **전량 검수 필수** |
| (빈칸) | 1,263종 1,693건 | 규칙 미적용. 빌드 시점 LLM 배치가 처리 (D-029) |

`규칙` 컬럼에 어떤 근거로 매핑됐는지 남아 있다. `수기`는 사람이 고친 행이다.

> **티어B는 정답지에서 정밀도 100%였으나 실제 미지 데이터에서 80%였다.** (D-031)
> 정답지가 빈도 상위 500종이라 꼬리의 `적겨자`(겨자잎 채소)·`흰목이버섯`(다른 종) 같은 함정이 없었다.
> **정답 세트로 잰 정밀도를 꼬리에 그대로 적용하면 안 된다.**

## 4. 주의 — `묶음`에 끌려가지 말 것

`묶음`은 이름이 겹치는 것끼리 모아둔 배치일 뿐이다. 같은 묶음 안에 다른 재료가 섞여 있다.
실제로 1차 편집에서 `고추장`이 `고추` 묶음에, `땅콩버터`가 `버터` 묶음에, `수수`가 `옥수수` 묶음에,
`미더덕`이 `더덕` 묶음에 들어가 있었다.

## 5. 결과를 서술할 때

**"재료명 정규화 정확도"가 아니라 "정의한 정규화 규칙 대비 일치율"로 쓴다.**
정답을 만든 사람과 접는 기준을 정한 사람이 같기 때문이다. (D-020)

측정은 두 층으로 나눈다 — **사전 커버율**(LLM 없이 처리된 비율)과 **미지 이름 정규화 정확도**.

메모에 `미검증`·`추정`·`코퍼스 외 지식 기반`이 적힌 행은 **집계에서 분리한다.** 코퍼스로 검증할 수 없는
라벨이라 모델이 맞힐 수 없고, 섞으면 정확도가 부당하게 낮게 나온다. 현재 해당 행은 5행 36건이다. (D-025·D-026)
