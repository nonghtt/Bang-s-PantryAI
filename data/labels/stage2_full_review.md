사람이 조리과정을 읽는 작업량이다.** 지금 23건인 것이 그 비용 때문이다.

### (c) 규칙 문서가 모호 — 19건

README에서 답이 유도되지 않고, 정답지와 산출물이 각자 다른 관례를 택한 지점이다. **어느 쪽이 옳다고
판정할 근거가 없어 정답지를 고치지 않았다.**

| 재료명 | 정답지 | 산출물 | README가 말하지 않는 것 |
| --- | --- | --- | --- |
| `어간장` · `간편 어간장` (11) | `간장` | `액젓` | 원료가 다른 장류를 이름 접미사로 접을 것인가. 정답지는 `저염간장`·`맛간장` → `간장` 패턴을, 산출물은 원료(어류)를 따랐다 |
| `다시마국물` (8) | `다시마` | `육수` | **우려낸 국물을 원물로 되돌릴 것인가.** 정답지는 원물로, 산출물은 `육수`로 통합했고 그 관례를 53행에 일관 적용했다. 어휘에는 `육수`·`닭육수`가 둘 다 있고 `닭육수 → 닭육수(그대로)`다 |

D-039가 보고한 *"규칙이 모호했던 지점 약 40개의 접기 관례를 세션이 스스로 정했다"*가 여기서
확인된다 — **다만 정답지와 충돌한 것은 2종 19건뿐이고, 나머지는 정답지 밖이라 채점되지 않았다.**
"세션이 스스로 정한 관례가 옳았는가"는 이번 채점으로 답이 나오지 않는다.

### (d) 어휘에 정답이 없었음 — 16건

`마늘기름`(12) · `마늘오일`(4). 레시피 원문이 정답을 확정해준다 —
**mfds/418 조리 4) "마늘을 다진 후 마늘기름으로 칵테일 새우를 볶아준다."** 한 문장 안에서 `마늘`과
`마늘기름`을 각각 다른 역할로 쓴다. 마늘이 아니다.

그런데 **`마늘기름`은 실행 세션에 전달된 목표 어휘 352종에 없었다.** `고추기름`은 있었다. 모델이 낼 수
있는 답은 `마늘`(정답지의 답, 원문이 반박) 아니면 `식용유`(산출물의 답, `고추기름 → 고추기름`과 어긋남)
둘뿐이었고, **정답은 선택지에 없었다.**

이 16건은 산출물의 오류로도 정답지의 오류로도 셀 수 없다. **어휘 자체의 결손이다** — 그리고 어휘는
정답지의 표준명 컬럼에서 자동 생성되므로, **정답지의 오류가 어휘를 통해 모델의 선택지를 좁힌
2차 피해**다. D-031이 관측한 *"라벨 결정이 규칙을 타고 증폭된다"*(`치즈 → 체다치즈`가 `생치즈`까지 전파)의 다른 형태다 — 그때는 규칙을 타고 번졌고, 이번에는 **어휘를 통해 선택지를 지웠다.**

정답지를 `마늘기름 → 마늘기름(그대로)`으로 고쳐 어휘는 353종이 됐지만, **산출물은 그대로 두었으므로
이 16건은 여전히 불일치로 집계된다.** 점수를 올리지 않는 수정이다.

## 6. 정답지 수정 4건 — 레시피 원문으로 확정

**모든 판단 근거를 레시피 원문으로 되돌릴 수 있는 것만 반영했다.**

### ① `적양배추 → 양배추` ⇒ `적양배추 → 적채` (표기) · 9행

결정적 증거는 mfds/541 `닭가슴살현미스테이크` 하나다. 재료에 `양배추 20g`과 `적양배추 20g`이
따로 있고, 조리과정이 이렇게 쓴다.

> 3) 양배추와 **적 양배추**는 곱게 채를 썰어 …
> 6) 양배추와 **적채**를 깔고 그 위에 튀겨진 닭가슴살을 올리고 …

**같은 레시피가 `적양배추`를 `적채`로 바꿔 부른다.** 원문이 직접 동일시한다. mfds/623도
"양배추, 적양배추는 채 썰고"로 둘을 병렬한다. 두 레시피에서 `양배추`와 동시 등장하므로
D-028("함께 나오면 다른 물건")로도 `양배추`로 접을 수 없다.

### ② `미소된장 → 된장` ⇒ `미소된장 → 일본된장` (표기) · 5행

`미소된장`(5건)과 `일본된장`(4건)은 **동시 등장 0건이고 용례가 완전히 겹친다** — 양쪽 다
가쓰오·다시마 육수에 풀거나(상추미소국·시금치된장죽) 구이소스로 쓴다(연어스테이크·삼치구이).
README §2의 판별 절차 그대로다: 동시 등장 0 + 용례 겹침 → 같은 물건.

한국 `된장`(76건)과 합치지 않는 이유는 D-022·D-024의 "결과물이 달라지는 차이는 구분"이고,
정답지가 이미 `일본된장`을 독립 표준명으로 세워둔 것과도 일관된다.

### ③ `마늘기름`·`마늘오일 → 마늘` ⇒ `마늘기름`(그대로) · `마늘오일 → 마늘기름`(표기) · 16행

3절 (d). 원문(mfds/418 "마늘을 다진 후 마늘기름으로")이 `마늘`을 반박하고, `고추기름 →
고추기름(그대로)`이 이미 있으므로 향유는 독립이 일관된다. `마늘오일`은 README의 확정 표기
관례(`올리브유`, 油 표기 통일)를 따라 `마늘기름`으로 접었다.

**이 수정은 일치율을 올리지 않는다** — 산출물의 `식용유`는 여전히 오답이다. 대신 이 16건이
"모델이 틀렸다"가 아니라 "어휘에 정답이 없었다"로 정확히 분류된다.

### ④ `와인` — 채점 분리 목록에 추가 · 4행

`와인` 4건의 조리과정 어디에도 색 표기가 없다. 스테이크 소스(mfds/506·481), 쪽갈비 삶는 물(375),
**먹물+식초+설탕 피클(654)** — 마지막은 육류도 토마토 요리도 아니고 피클이라 화이트도 흔하다.
정답지 메모의 "육류·토마토 계열 → 레드 추정"은 관찰로는 옳지만 판별 근거는 아니다.

같은 코퍼스에 `화이트와인` 19건이 별도로 있다 — **원천은 색을 구분해서 쓰며, 색을 안 쓴 4건은
작성자가 명시하지 않은 것이다.** 정답지 메모가 스스로 "추정 · 오판 상한 4건"이라 적어둔 대로
README §5의 분리 대상이고, 산출물의 `판별불가`가 정직한 답이다.

**이것은 채점 스크립트 수정이므로 사유를 먼저 적는다.** `CONTEXT_DEPENDENT` 상수는 README §5가
메모 기준으로 정의한 분리 규칙을 손으로 옮겨 적은 것이라, 정답지에 `와인` 행이 추가됐을 때
조용히 어긋났다. **상수와 규칙의 동기화 누락이지 채점 결과에 맞춘 조정이 아니다.**

같은 종류의 사고가 다시 나지 않도록 채점기에 검사를 넣었다 — **메모에 신호어가 있는데 상수에
없으면 채점하지 않고 멈춘다.** 이 검사를 넣자마자 `밥`이 걸렸는데, 메모의 "역방향 미검증"은
라벨이 아니라 *쌀→밥 대체 방향*에 붙은 말이라 채점 대상이 맞다. **메모가 자유 텍스트라
"무엇이 미검증인가"가 구분되지 않는다** — `EXCLUSION_REVIEWED`에 판단을 적어 예외로 뒀다.

## 7. 커버리지 실측 — 추정치 교체

`scripts/measure_coverage.py`를 재고 21종 · 제외 목록 · 매칭 방식 그대로 두고 입력만 전량 산출물로
바꿨다. (정답지 수정 4건은 상비 재료를 건드리지 않아 수치가 바뀌지 않았다.)

| 지점 | 도달 가능 | 건수 |
| --- | ---: | ---: |
| 정규화 전 · 정확 일치 | 3.3% | 56 |
| 정규화 전 · 부분문자열 | 4.6% | 77 |
| 정규화 후 · 추정 (파일럿 49건 + 이름 단위 매핑) | 5.3% | 90 |
| **정규화 후 · 실측 (전량 산출물 18,988행)** | **5.9%** | **100** |

**추정치는 과소평가였다** — 실측이 10건(+0.6%p) 높다. 이름 단위 매핑이 담지 못한 맥락 판정과
꼬리 재료만큼이 실측에서 드러났다.

정규화 효과: **3.3% → 5.9% (+2.6%p, 56→100건, 1.79배)**. 부분문자열 매칭이 이미 내던 효과를
빼면 **4.6% → 5.9% (+1.3%p, 1.30배)**.

출처별로는 격차가 훨씬 크다.

| 출처 | 정규화 전(정확 일치) | 정규화 후(실측) | 배수 |
| --- | ---: | ---: | ---: |
| 농정원 | 8.8% (47/537) | 12.8% (69/537) | 1.47× |
| 식약처 | 0.8% (9/1,152) | 2.7% (31/1,152) | **3.44×** |

**정규화가 크게 남는 쪽은 재료명을 길게 쓰는 식약처다.** 정확도 격차는 0.23%p로 거의 없는데(1절)
커버리지 효과는 3.4배 대 1.5배로 갈린다 — 정규화의 가치는 정확도가 아니라 **원본 표기가 얼마나
흩어져 있었는가**에서 나온다.

**한계.** `measure_coverage.py`의 `resolve()`는 행 단위 정답(사람이 만든 23행)을 산출물보다
우선한다. 추정치와 같은 자를 쓰기 위해 방법을 바꾸지 않았으나, 이 5.9%는 순수한 산출물 단독
측정이 아니라 **23행이 사람 답으로 대체된 값**이다. 그 23행 중 8행은 산출물이 틀린 행이므로(4절)
산출물 단독 측정은 이보다 조금 낮다.
